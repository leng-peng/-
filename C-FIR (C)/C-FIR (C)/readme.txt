README.C-FIR		Example ADSP-21062 FIR C Program

Analog Devices, Inc.
DSP Division
P.O. Box 9106
Norwood, MA 02062

This directory contains an example C program for use with 
the ADSP-21062 Development Software. The example program is a FIR
filter written in C.   

Files contained in this directory:
FIR.C		ADSP-21062 C program which implements an FIR filter.
FIR.DPJ		The VDSP project file for the C example.  The FIR project is
  		configured to produce a DXE file named FIR.dxe.
